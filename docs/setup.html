Local environment

Get SpendSync running.

Start the supporting services, run the Spring Boot API, then launch the React application. Each part can be run independently during development.

01 Prerequisites

Install these tools before starting the application.

Java 21+Backend runtime
Node.js 18+Frontend runtime
Docker & ComposeLocal infrastructure
02 Infrastructure

Start the local services.

The Docker Compose configuration starts PostgreSQL, Redis, and RedisInsight.

docker compose -f docker/docker-compose.yml up -d
PostgreSQLlocalhost:5432
Redislocalhost:6379
RedisInsighthttp://localhost:5540
03 Backend

Launch the API.

From the repository root, enter the backend directory and start Spring Boot.

cd backend
mvn clean spring-boot:run
API serverhttp://localhost:8080
Swagger UIhttp://localhost:8080/swagger-ui.html
Health probehttp://localhost:8080/actuator/health
04 Frontend

Run the web application.

Install the frontend dependencies once, then start Vite’s development server.

cd frontend
npm install
npm run dev
Web applicationhttp://localhost:5173
05 Tests

Run the backend test suite.

The test command also produces a JaCoCo coverage report.

cd backend
mvn clean test

Coverage report: backend/target/site/jacoco/index.html
